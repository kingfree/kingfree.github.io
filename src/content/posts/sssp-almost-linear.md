2026 年 11 月 25 日，Iman Gholami 与 MohammadTaghi Hajiaghayi 把《Linear Single-Source Shortest Path, Almost》挂上 arXiv。结论很短：无向图、非负实数边长、比较–加法模型，单源最短路可以在 $O(m + n\log\log\log n)$ 期望时间内算完，而且这个界与边长之间的比值无关。

它的意义在于绕开了排序。把 $n$ 个实数距离排好序本身要 $n\log n$，但"算出这些距离"并不需要真的把它们排出来。从 Dijkstra 的顶点抽取顺序、Thorup 的整数权重分层，到 Pettie–Ramachandran 的层级，这条路走了二十多年；近几年的进展是 Duan–Mao–Shu–Yin 的 $m\sqrt{\log n\log\log n}$ 随机算法与其确定性版本。这篇论文把两个对数都压成了 $\log\log\log n$。

我把它全文译成了中文，用 Typst 重排；同时把论文的算法用 C 实现了一遍，并与 Dijkstra 逐顶点对拍。

- [代码与 Typst 源文件](https://github.com/kingfree/sssp-almost-linear)
- 原文：[arXiv:2611.34911](https://arxiv.org/abs/2611.34911)

译文保留了全部 48 条引理、7 个定义、1 个主定理、8 个算法与 49 个证明；算法伪代码按 Function / Input / Output 与缩进层次重排，两张 TikZ 图用 Typst 重画。

C 实现按论文的结构分文件：比较–加法长度模型（长度只允许复制、相加、比较与倍增）、最小生成树的三趟有界生长、归属分解、枢纽路由证书（算法 2、3）、归属坐标 $J$、外层状态图（双壳窗口、近/远转移、相位切换、宏观重置）、阈值分量与层级组装。在 $n = 20\ldots100$ 的随机图上对拍全部一致，$n = 800$ 也对。

诚实地说，最后一环——算法 7/8 的时间槽扫描——目前只在部分实例上正确；所以默认路径改成了"在构造出的状态图上做精确搜索"。这验证的是 §8.1 的构造确实以原长度实现了每条物理测地线（引理 8.1、5.5），而不是验证求值过程本身。已知偏差与后续要补的部分都写在仓库 README 里，没有含糊过去。

一句话总结：论文给出了"不排序也能算出距离"的路线，我把它译成了中文，并把其中能被独立验证的部分跑了一遍。
